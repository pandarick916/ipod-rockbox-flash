# 字体高度与配色手册

两个最容易翻车的地方：**字体高度对不上会被裁**，**配色改法不对会被覆盖**。

---

## 一、字体真实高度（实测）

文件名开头的数字是**名义字号**，不是真实渲染高度。真实高度在 `.fnt` 文件头里。

### 读法

Rockbox 新字体格式的魔数是 `RB12`（不是别人常说的 `FNT`）：

```
offset 0-3   "RB12"
offset 4-5   最大宽度 (u16 LE)
offset 6-7   真实高度 (u16 LE)   <-- 要的就是这个
offset 8-9   ascent
```

```python
import struct
head = open(path, 'rb').read(16)
if head[:4] == b'RB12':
    maxw, height = struct.unpack('<HH', head[4:8])
```

### 主题原字体（Themify 2）

| 字体 | 名义 | **真实高** |
|---|---|---|
| `22-LeagueSpartan-Regular` | 22 | **18** |
| `22-LeagueSpartan-Bold` | 22 | **23** |
| `18-LeagueSpartan-Medium` | 18 | **15** |
| `24-LeagueSpartan-Regular` | 24 | **19** |

**关键**：`18-LeagueSpartan-Medium` 名义 18，实际只有 **15**。所以中文字体按"18px"去挑，一定会超。

### 为什么数字能塞进去、中文不能

拉丁字体里数字只占基线上方那一段（约字高的 70%），下方留白。所以 15 高的字体，数字实际只占 11px，塞进 12px 的框没问题。

中文字形**占满整个 em 框**，17 高的字体就是 17px 实体，塞进 12px 的框会被上下各裁一截——表现是"显示不全"而不是"完全不显示"。

### 换字体的正确做法

1. 先用 `diagnose.py` 看主题每个字体 id 用到的最小 viewport 高度
2. 选一个**真实高度 ≤ 那个最小高度**的 CJK 字体
3. **保留文件名**，只替换内容（原文件备份成 `.orig-en`）

Themify 2 的实际需求：

| font id | 用途 | viewport 高度 | 该选 |
|---|---|---|---|
| 2 | 歌名 | 18, 60 | 高 ≤18，如 `16-SFPro-Regular-CJK`(17) |
| 3 | 子文本 / 时间 / 播放位置 | **12**, 16, 18 | 高 ≤12，或把框撑大 |

**如果不想用 12px 的小字**：改 `.wps` 里 `%Vl(Playlist_Position_*,x,y,w,12,3)` 的 `12` 为 `18`，再配 17 高的字体。改之前备份 wps。

## 二、配色

### 只有两个值

Themify 2 这类皮肤，颜色由 `config.cfg` 的这两行决定：

```
foreground color: d8c68e
background color: 1a110c
```

皮肤里没有硬编码颜色（实测 `%Vf()` 出现 0 次），所有区域用 `%VB` 填充，吃的是全局背景色。所以改这两个值就是全部。

### 但不要直接改 config.cfg

**Rockbox 在运行时会把它覆盖回去。** 插着线的时候 Rockbox 是活的，内存里有旧设置，任何一次保存（改设置、关机、退出 USB 模式）都会写回文件，把外部修改冲掉。

**正确流程**：

1. 在 `.rockbox/` 根目录放几个独立命名的小 `.cfg`（每个几百字节）
2. 让用户在 `设置 → 管理设置 → 浏览 .cfg 文件` 里加载
3. 加载后 Rockbox 自动存成当前配置，持久生效

每个 cfg 要带完整设置（音量、背光、语言、wps/sbs），否则加载后会出现"只换了一半"的状态。

**cfg 必须是纯 ASCII**：注释行写中文会被写成问号，可能影响整行解析。颜色值用 6 位 hex，不带 `#`。

### 十套现成配色

设计约束：底色明度压在 4–12%，前景 68–90%，对比差 ≥58。这样八套摆在一起才有区分度——如果底色全在 8–9%、前景又都是黄系，看起来就会"几套一样"。

| # | 名称 | 背景 | 前景 | 对比差 | 感觉 |
|---|---|---|---|---|---|
| 1 | 墨夜·米金 | `0E0B07` | `F0D9A8` | 82 | 近黑 + 米金，最高对比 |
| 2 | 酒红·藕粉 | `241016` | `F2B0C4` | 69 | 深酒红 + 粉，最有氛围 |
| 3 | 焦褐·琥珀 | `2A1A0E` | `E8A862` | 58 | 暖褐 + 橙，最活泼 |
| 4 | 紫檀·象牙 | `191322` | `E8DCC8` | 78 | 紫底 + 象牙，最雅 |
| 5 | 橄榄·苔绿 | `11150C` | `B9CF8E` | 69 | 橄榄 + 苔绿，最清新 |
| 6 | 深赭·米白 | `1E1710` | `EDDFC4` | 78 | 字最亮，最清晰 |
| 7 | 石墨·银白 | `0D0D0F` | `DCDEE2` | 82 | 纯中性，极简 |
| 8 | 青瓷·月白 | `0C1A18` | `D8EDE4` | 82 | 青瓷 + 月白，最清爽 |
| 9 | 海湾·橙 | `081420` | `F59A56` | 61 | Gulf 涂装，橙蓝对撞 |

### 挑配色的判断依据

- **LCD 屏（iPod Classic 就是）**：前景明度低于 65% 会发灰，优先选 70% 以上
- **暖 / 冷**：底色和前景同为暖或同为冷最协调；暖底 + 冷字（或反之）看个性，但要控制饱和度
- **对比差 < 58**：小字会看不清，尤其"3 of 12"这种 10px 的字
- **配色和专辑封面会打架**：暖色底配冷调封面会显脏，选色时想一下常听的歌

### 连线选择器

菜单里选中那一行要高亮，需要三个值：

```
line selector start color: <前景色>
line selector end color: <前景色>
line selector text color: <背景色>
```

即反色：前景色做底，背景色做字。不加这三行会沿用上次主题的，可能变成看不懂的组合。
